SmartTask Privacy Policy

Last Updated: November 2026

1. Data Collection & Sovereignty

SmartTask stores account, workspace, task, invitation, and comment data in the Supabase cloud project configured for this app. Authentication is handled by Supabase. Data access depends on the database Row Level Security (RLS) policies and server-side functions configured for the project. Do not enter sensitive information unless the workspace owner has approved the project's security and privacy settings.

2. Enterprise Deployment Keys & Security

To ensure total data sovereignty, administrative configurations—including your Cloud Project URL and Public Connection Keys—are managed strictly within the authorized administrator's environment. These credentials are structurally encapsulated within the application's runtime and remain entirely inaccessible to the app creators or third-party interceptors.

3. Third-Party Service Providers

The application utilizes industry-standard cloud providers to orchestrate seamless task tracking:

• Supabase: Used for private data architecture and secure user authentication.

• EmailJS: Used by the app to send workspace invitation and comment-notification emails. Email delivery depends on the configured EmailJS service, template, account limits, and recipient settings.

All telemetry and data interactions are governed by the respective security protocols of these platforms.

4. Data Export & Rights

Enterprise users retain full ownership of their operational data. Administrators can extract and download localized backups at any time via the "Export Data" functionality located within the user preferences panel.
